# IT Helpdesk Ticket Registration System

## 1. Purpose of the Application
The IT Helpdesk Ticket Registration System is a modular Python program designed for the IT Support team at City University Malaysia. It allows students to report technical issues (e.g., LMS login, Wi-Fi errors) and automatically assigns a support technician based on the issue's priority level.

## 2. Tech Stack
* **Language:** Python 3
* **Tools:** Visual Studio Code / Terminal / Git & GitHub

## 3. How to Use
1. Open your terminal or command prompt.
2. Navigate to the `week_9` directory:
   ```bash
   cd week_9
   ```
3. Run the main script:
   ```bash
   python main.py
   ```
4. Enter the required details when prompted (Student Name, Student ID, Issue, Location, Priority).
