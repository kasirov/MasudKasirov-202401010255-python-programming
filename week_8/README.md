# Week 8 - Food Delivery System

## Purpose

This application is a simple Food Delivery System developed in Python.
It collects customer information, calculates the receipt, and displays the total payment.

---

## Tech Stack

- Python 3
- VS Code

---

## Files

- main.py
- customer.py
- receipt.py

---

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

python main.py

4. Enter the customer details.
5. The receipt will be displayed.

---

## Features

- Customer information input
- Food ordering
- Delivery option
- Automatic subtotal calculation
- 5% service charge
- RM5 delivery charge (if selected)
- Grand total calculation
